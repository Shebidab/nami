# Shortcuts & gestures

Small moves that make your desk easier to use.

In Nami, click **Shortcuts** at the bottom right, open **Settings → Shortcuts**,
or choose **Help → Keyboard Shortcuts**. The reference works offline, and it
shows the keys for the machine you are on — the tables below list both.

## Open what your agent makes

Hold **⌘** (Windows: **Ctrl**) and click a link or file path in a session. Web
links open in your browser. Files open here in Nami. Hover a link for a
reminder, or right-click it for the available actions.

| Action | macOS | Windows |
| --- | --- | --- |
| Open a web link in your browser | ⌘ + click | Ctrl + click |
| Open a file in Nami | ⌘ + click | Ctrl + click |
| Reveal a file in Finder / Explorer | ⌥⌘ + click | Ctrl + Alt + click |
| Reveal a folder in Finder / Explorer | ⌘ + click | Ctrl + click |
| Open, copy, or reveal a link | Right-click | Right-click |

These gestures apply to session output. Links in a document's **Read** mode
open with a normal click. Missing file paths can still be copied from their
right-click menu; an open hint appears only when Nami can resolve the target.

## Everyday shortcuts

| Action | macOS | Windows |
| --- | --- | --- |
| New session | ⌘N | Ctrl+N |
| Open the agent picker | ⌘K | Ctrl+K |
| Open a folder | ⌘O | Ctrl+O |
| New window | ⇧⌘N | Ctrl+Shift+N |
| Open Settings | ⌘, | Ctrl+, |
| Save the active file | ⌘S | Ctrl+S |
| Close the active pane | ⌘W | Ctrl+W |
| Dismiss a dialog or leave an expanded pane | Esc | Esc |

## Arrange your desk

| Action | Gesture |
| --- | --- |
| Reorder a pane | Drag its header |
| Resize a pane | Drag its resize handle |
| Reset a pane's size | Double-click its resize handle |
| Rename a session | Double-click its title |

## In the workspace

| Action | macOS | Windows | Where |
| --- | --- | --- | --- |
| Rename the selected file or folder | Return | Enter | Workspace list has focus |
| Move the selected item to Trash | ⌘⌫ | Ctrl+Del | Workspace list has focus |
| Add selected file content to a session | ⇧⌘Return | Ctrl+Shift+Enter | File selection toolbar |

**⌘** Command · **⌥** Option · **⇧** Shift · on Windows, **Ctrl**, **Alt** and **Shift**

Shortcuts inside an agent's terminal can vary by agent. This reference covers
Nami's controls.
